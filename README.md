# صانع قوائم الطلاب

صفحة تعريفية عربية لبرنامج **صانع قوائم الطلاب**، جاهزة للنشر باستخدام GitHub Pages.

## محتويات المشروع

- `index.html`: الصفحة الرئيسية.
- `assets/style.css`: التصميم المتجاوب.
- `assets/script.js`: قائمة التنقل في الهواتف.
- `downloads/صانع قوائم الطلاب.exe`: البرنامج لنظام Windows.
- `downloads/بيانات الفصول.xlsx`: قالب إعداد الشعب وأعداد الطلاب.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا وارفع جميع ملفات المشروع إليه.
2. افتح **Settings** ثم **Pages**.
3. تحت **Build and deployment** اختر **Deploy from a branch**.
4. اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. سيظهر رابط الموقع بعد اكتمال النشر.

## ملاحظة الاستخدام

الإصدار الحالي يوزع الطلاب بالتسلسل حسب ترتيبهم في ملف Excel؛ لذلك ينبغي ترتيب قائمة الطلاب مسبقًا بالشكل المطلوب قبل تنفيذ التقسيم.
